## 根因分析（已归档）
```
超参 sweep 的 228 个 configs 使用不同的超参数组合。
原逻辑：用「最佳已知准确率」（来自 best-performing config per model×dataset）
对所有 228 个 configs 做回归检测。
问题：non-baseline configs 的准确率自然低于最佳值，被错误标记为 regression。

示例：SVM|circles，BASELINE_CONFIGS=[C=1.0]，但 sweep 中 SVM|C=0.1 的 circles 准确率
是 0.79 < 0.80 * 0.95 → 被标记为 regression。

修复：regression detection 只在 params == BASELINE_CONFIGS[model_name] 时触发。
这样只有「使用了 baseline 超参数的配置」才参与回归检测。
```
