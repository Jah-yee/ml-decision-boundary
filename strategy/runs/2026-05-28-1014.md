## 根因分析：respx/httpx 冲突

**现象**：本地 pytest 收集阶段就失败（pytest 加载 respx 时尝试 import httpx.BaseTransfer）

**根因**：
- `respx 0.23.1` 是一个全局安装的 pytest plugin（注册在 `pytest11` entry point）
- 它依赖的 `httpx 0.28.1` 也全局安装在系统 site-packages
- httpx 自 0.27.0+ 移除了 `BaseTransport`（从 HTTPX 改为 `BaseTransport` → `AsyncBaseTransport`）
- respx 0.23.1 尚未兼容 httpx 0.28（需要升级 respx 到 0.24+）

**CI 不受影响原因**：
- CI 只安装 `requirements.lock`（不包含 respx 或 httpx）
- pytest 运行时不加载 respx plugin
- 所有测试不依赖 respx（grep 结果为空）

**修复方案**：
- 方案A（推荐）：pip install respx==0.24.0+（修复 httpx 0.28 兼容性）
- 方案B：卸载全局 httpx/respx，让测试环境隔离
- 方案C：conftest.py 中添加 `sys.modules['respx'] = None` 隔离
