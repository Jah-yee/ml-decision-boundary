## 3. v12 DoD #1 交付：Python SDK（`ml_db`）

### 3.1 设计原则

SDK **只封装 `core/`，零复制训练逻辑** → CLI / HTTP API / SDK 三端结果永不漂移。

### 3.2 交付文件

| 文件 | 行数量级 | 内容 |
|------|---------|------|
| `ml_db/__init__.py` | ~30 | 顶层导出 `MLDB` / `TrainResult` / 异常族 / `__version__="0.1.0"` |
| `ml_db/client.py` | ~330 | `MLDB` 客户端 + `TrainResult` dataclass |
| `ml_db/errors.py` | ~80 | `MLDBError` 基类 + 4 个子类（E2001-E2004） |
| `tests/test_sdk.py` | ~200 | 21 个测试 |
| `examples/06_sdk_usage.py` | ~110 | 可运行走查脚本 |
| `core/train_utils.py` | 改 | 抽出模块级 `BUILTIN_FACTORIES` / `BUILTIN_MODEL_NAMES` |

### 3.3 `MLDB` 公开 API

| 方法 | 签名要点 | 说明 |
|------|---------|------|
| `datasets()` / `models()` | staticmethod | 枚举 8 数据集 / 10 内置模型 |
| `dataset(name, n_samples, noise, seed)` | → `(X, y)` | 原始数据访问 |
| `train(model, dataset, params, n_samples, noise, test_size, register, tags)` | → `TrainResult` | 训练 + 评测 + 注册（可 `register=False`） |
| `predict(model_id=..., X=..., model=...)` | → `list` | 单点/批量预测，`model_id` 与 `model` 二选一 |
| `predict_batch(...)` | → `dict` | 结构化返回 `{predictions, count, model_id}` |
| `list_models()` / `get_model()` / `load_model()` | registry 直通 | |
| `tag()` / `untag()` / `list_tags()` / `list_models_by_tag()` | 标签能力 | |
| `compare(id1, id2)` | 对比 | |

### 3.4 `TrainResult` 字段

`model_id` / `model_type` / `dataset` / `accuracy` / `train_accuracy` / `train_time` / `params` /
`metadata` / `model`（内存中的 estimator），外加 `to_dict()` 便于 JSON 序列化。

### 3.5 错误契约（E2xxx 段位，延续仓库 E1xxx 约定）

| 码 | 异常 | 触发 |
|----|------|------|
| `E2001_UNKNOWN_DATASET` | `UnknownDatasetError` | 数据集名不存在 |
| `E2002_UNKNOWN_MODEL` | `UnknownModelError` | 模型名不存在 |
| `E2003_MODEL_NOT_FOUND` | `ModelNotFoundError` | registry 中无此 model_id |
| `E2004_INVALID_INPUT` | `InvalidInputError` | X 形状非法 / 缺模型 / test_size 越界 |

全部继承自 `MLDBError`，调用方可一次性捕获。
