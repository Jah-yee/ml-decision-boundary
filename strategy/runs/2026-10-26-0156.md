## 三、本轮实现

### 3.1 核心模块 `core/provenance.py`（新）

| 符号 | 作用 |
|------|------|
| `canonical_json()` | sorted keys + 紧凑分隔符的稳定 JSON 渲染 |
| `environment_info()` | python / implementation / platform / numpy / scikit_learn / joblib 版本 |
| `git_info()` | commit / branch / dirty；非 git 目录不抛异常（降级为 `unknown`）|
| `compute_fingerprint()` | canonical JSON + SHA-256（前 16 hex），前缀 `sha256:` |
| `build_provenance()` | 组装完整记录：`seed` / `dataset` / `hyperparameters` / `model_type` / `environment` / `git` / `captured_at` / `fingerprint` |
| `provenance_diff()` | 结构化差异：`{field, left, right}` 列表 + `identical` / `fingerprint_match` |

### 3.2 三端接入

- **Registry（事实源）**：`save_model(provenance=...)`、`get_provenance()`、`compare_provenance()`；`_normalize()` 对旧模型补 `provenance={}`。
- **SDK**：`MLDB.get_provenance()` / `MLDB.compare_provenance()`；模型缺失抛 `ModelNotFoundError`。
- **CLI**：`python3 main.py model provenance <id>`、`python3 main.py model diff <id1> <id2>`。
- **HTTP**：`/api/registry` 返回体自动携带 `provenance` 字段（无需改端点契约）。

### 3.3 设计决策

| 决策 | 理由 |
|------|------|
| 指纹覆盖 seed/dataset/hyperparams/环境版本/git commit | 这些是复现实验的充分条件 |
| 指纹**不**覆盖 `captured_at` / `git.dirty` / `git.branch` / `environment.platform` | 这些是采集上下文而非复现条件；否则会出现"指纹相同但记录不同"的语义冲突（platform 在不同机器上易变）|
| diff 比较结构化值而非 JSON 字符串 | 字符串比较会把 `{"C":1.0}` 与 `{"C":1}` 判为不同（前者 `"1.0"`，后者 `"1"`），也会被 key 顺序影响 |
| 旧模型读回 `{}` 且**不重写**原 JSON | 延续 v12 "零迁移"纪律，用字节级相等断言守护 |
